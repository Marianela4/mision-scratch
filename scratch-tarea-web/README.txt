DETECTIVE DE BLOQUES

Publicar en GitHub Pages:
1. Crea un repositorio público.
2. Sube todos estos archivos, sin subir la carpeta contenedora ni el ZIP.
3. Ve a Settings > Pages.
4. Elige Deploy from a branch, rama main y carpeta /(root).
5. Guarda y abre la dirección publicada por GitHub.

La actividad guarda las respuestas en el navegador y funciona sin conexión después de abrirla una vez.
